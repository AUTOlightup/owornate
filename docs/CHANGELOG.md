# 版本记录

## 1.0.0 / versionCode 7 — 独立实机验收通过（本地候选，建议标签 `v1.0.0-rc2`）

- 修复 `standalone/module-manage.sh` 的 `restart_launcher` 对 `/proc/<pid>/cmdline` NUL 填充的误判：改为按空白切分后的单参数身份检查，停用 / 卸载现在会真正重启 Launcher。
- 在原表临时隔离生产组件、只重建本包数据、已有 root 的独立环境完成实机验收：首次 `Setup` 部署、表端独立安装、fixed / 雾蓝 / 淡紫 / original / auto 与圆角实时生效、单步恢复、停用 → 启用、卸载 → 重装均通过；模块生命周期模拟测试 56/56 通过。不是出厂重置，也不是另一块新表。
- 整机重启后、首次打开 OWOrnate 之前由 APP 原生代码自行恢复，无需电脑发送 ensure 命令；`VerifyBoot` 核对通过。电脑保留 ADB 取证与输入连接，未声称物理断开。
- 验收结束后原表恢复到隔离前的原 code6 环境：八个原生产组件、原 APP 数据、ADB 授权与系统设置与隔离前逐一一致。
- APK `OWOrnate-v1.0.0.apk`，152,717 bytes，SHA256 `39e96a6ac06ef7d43aae96af530edebc71478f48605e1eec10ea0f4786f5d9f5`，包名 `dev.codex.watchworkshop` 与签名沿用。本版为 RC2 候选。未测边界：长期功耗、MCU 换色、其他机型与固件、空白表复跑。

## 1.0.0 / versionCode 6 — 历史（原“正式版目标”，code6 候选）

品牌由“腕上工坊 (WatchWorkshop)”统一为 **OWOrnate**：系统应用标签、公开文档与产物文件名同步更名；包名 `dev.codex.watchworkshop`、签名与运行目录保持不变。产物文件名：APK `OWOrnate-v1.0.0.apk`、Windows 包 `OWOrnate-v1.0.0-Windows.zip`、源码包 `owornate-v1.0.0-source.zip`，主题源码包保持 `watch2-monet-v6-source.zip`。APK SHA256 `d7cf96096b72c00a14157042c55621215069da08e432d7809d24f9843d5036fe`。

界面与交互调整：

- 首页只保留“我的优化”“发现优化”两个栏目，去掉栏目子标题、去掉“最近操作”与“返回表盘”按钮；右滑仍是返回 / 退出手势。
- 已安装项进入同一莫奈配置页，右上角开关直接启用 / 停用，不再经“优化管理”中转；停用后仍可进入该页查看。
- 配置实时生效：选择配色方式、固定颜色或连续圆角后直接提交，页面内给出轻量反馈，去掉“应用更改”按钮与常规应用确认页；快速连续修改串行收敛到最新一次选择。
- 页底提供“当前版本”、卸载与单步“恢复上一次设置”；“导出配置”移到技术详情，语义为已确认设备配置快照。
- 发现优化始终进入商店式介绍页：未安装提供安装（仍有一次安装确认），已安装（含已停用与共享接入）统一沉底并把主按钮改为“打开配置”；安装完成回到介绍页，卸载后回到“我的优化”。
- 共享接入项不能单独卸载，配置页底如实说明，仍可经右上角开关停用 / 启用；“系统原色 + 关闭圆角”不再被误判为用户停用。
- 删除旧 `versions`“优化管理”页；旧记录页、应用确认页恢复时进入合理页面，不再落入已删除页面，也不自动应用旧草稿。

本版正式发布前仍需空白 root 手表首次部署、模块生命周期与整机重启恢复的实机验收；建议标签 `v1.0.0-rc1`，尚未上传。下面 code5 及更早的条目均为历史基线，其中的 SHA256 与测试结论只对应各自构建，不代表本版。

## 1.1.0 / versionCode 4 — 历史候选

空白 root 手表首次部署、手表端模块生命周期与整机重启恢复为待实机验收；本候选件不描述为已完成，不宣称广泛支持，也不宣称已可通过应用商店上架。

新增与变更：

- 修复右滑直接退出：子页逐级返回，首页返回表盘；等待页禁止中途返回，结果页返回对应的配置/管理页。
- 已安装项从“我的优化”和“发现优化”直达同一配置/管理入口；取消外观分类中转和重复详情，合并设备信息与运行环境，操作记录保留首页入口。
- 固定颜色入口只在固定模式展示；优化管理中的配置入口保持一致，回到已有页面时复用返回栈。

- 部署模型改为“电脑一次、手表日常”：Windows 包 `00-Setup.cmd`（`release-manage.ps1 -Action Setup`）只安装管理器 APP、授权本机 ADB 公钥、部署 Frida 基础运行文件与 APP 恢复服务（仅独立设备启用），不安装莫奈模块。
- 莫奈模块随签名 APK 内置（`assets/monet/`：`theme.jar`、`hook.js`、`monet-service.sh`、`module-manage.sh`），安装、停用、启用、卸载与重新安装都在手表上完成，不需要电脑或联网下载。
- 部署脚本 Action 改为 `Setup|Status|RemoveManager|VerifyBoot`，`Install` 保留为 `Setup` 别名；Windows 双击入口为 `00-Setup.cmd`（Setup）与 `01-Status.cmd`（Status）。
- 运行目录仍为 `/data/local/tmp/watchworkshop-runtime`：`manager-ready` + Frida 基础运行文件 + `install-state.json` 为基础；`installed` 表示莫奈已安装，`disabled` 表示已停用。
- 模块卸载仅删除 `theme.jar`、`hook.js`、`monet-service.sh` 与 `installed` / `disabled`，保留基础运行文件、ADB 授权、APP 恢复服务、草稿与主题偏好，之后可再次安装。
- 界面按原设计稿还原：首页为运行状态摘要加“我的优化”“发现优化”“最近操作”与“返回表盘”；未安装时沿“发现优化 → 莫奈取色 → 安装方案”点“安装并启用”离线安装；管理入口为“优化管理”，提供停用、启用、恢复上一次设置与卸载。
- 主题不再直接应用：在“控制中心主题”选择配色方式、固定色（仅固定模式）与连续圆角后，点“应用更改”进入“应用方案”确认；应用只改动控制中心，确认后立即生效、无需重启表盘。“恢复上一次设置”有独立的“恢复设置”确认页。
- 共享组件：识别复用既有 watchhide v9 + helper v6，停用设为系统原色并关闭连续圆角，启用恢复之前配色；不能单独卸载共享主题，界面说明原因。
- 在系统里卸载 APP 会清除 APP 自己的草稿与记录；`RemoveManager` 移除本次首次部署的基础运行件，不清理 QQ 数据、登录状态与输入法词库。
- 自有代码采用 MIT，仓库根保留 `LICENSE`；第三方声明随安装包在 `licenses/` 提供。
- 在线模块目录与下载尚未接入，本版只有内置莫奈可离线在表端安装。
- 预发布标签建议 `v1.1.0-rc1`，以 GitHub 预发布形式提供；正式发布前需完成空白表首次部署、模块生命周期与整机重启验收。

首发只内置莫奈一个模块，发现优化直接列出内置项并标明来源；其他模块与在线目录尚未接入。
