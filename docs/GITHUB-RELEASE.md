# GitHub 首发材料

当前推荐标签 `v1.0.0-rc2`，创建预发布（Prerelease）。本轮材料用于在 AUTOlightup 的 owornate 与 watch2-monet 两个公开仓库发布该预发布。

## 两个仓库

| 建议仓库名 | 导入内容 | 用途 |
|---|---|---|
| `owornate` | 解压 `owornate-v1.0.0-source.zip` | 管理 APP、完整构建与部署脚本、内置莫奈模块 |
| `watch2-monet` | 解压 `watch2-monet-v6-source.zip` | 独立主题源码、HCT、控制中心外观、Launcher 桥接、主题协议 |

这两份源码不包含签名私钥、设备 ADB 私钥、个人日志或 OPPO 系统 APK。APP 源码也保留主题源码，便于完整构建；单独的主题仓库方便后续按功能发布。目前尚未接入在线模块目录，本版只有 APK 内置的莫奈可离线在表端安装。

## 发布标题

OWOrnate 1.0.0 RC2 · 电脑一次部署、手表实时调整莫奈配色

## 可直接采用的发布正文

OWOrnate 让 OPPO Watch 2 的控制中心配色跟随表盘，也支持固定颜色、系统原色与连续圆角。

1.0.0 起，电脑只需部署一次：运行 Windows 包里的 `00-Setup.cmd` 安装管理器 APP、授权本机 ADB 公钥并部署基础运行件与恢复服务（仅独立设备启用），不安装莫奈模块。之后在手表上即可安装、启停、调整与卸载莫奈。莫奈模块随签名 APK 内置，离线在表端安装，不需要电脑或联网下载。设备上已有原综合优化时，管理器识别复用共享主题能力，只提供停用 / 启用并如实说明不能单独卸载。

本版把配置流程改为实时生效：首页只保留“我的优化”和“发现优化”两个栏目、不显示子标题，去掉“最近操作”与“返回表盘”按钮（右滑退出）；在莫奈配置页选择配色方式、固定色与连续圆角后直接提交，不再有“应用更改”和常规应用确认页；启停是同一配置页右上角的开关，页底提供当前版本、卸载与单步恢复；“导出配置”移到技术详情，作为已确认设备配置快照。“发现优化”始终进入商店式介绍页：未安装提供安装（仍有一次安装确认），已安装（含已停用与共享接入）统一沉底并把主按钮改为“打开配置”；安装完成回到介绍页，卸载后回到“我的优化”。旧“优化管理”中转页已删除。

读取与实时提交期间仍可浏览、返回；提交期间暂不可启停、卸载或发起冲突写入，安装/卸载等待页完成后再返回。数量未知时概览显示“—”和中性色状态点。

首版适配 OPPO Watch 2 46mm（OW20W1）A.92 / Android 8.1，需已有 root adbd。本版是本地 RC 候选：独立首次部署、表端模块生命周期与整机重启恢复已在本轮独立实机环境通过（在原表临时隔离生产组件、只重建本包数据、已有 root）。尚未上传或发布。当前仅改变 Android 控制中心，MCU 轻智能表盘不在范围内。

下载附件：`OWOrnate-v1.0.0-Windows.zip`、`OWOrnate-v1.0.0.apk`、`owornate-v1.0.0-source.zip`、`watch2-monet-v6-source.zip` 和 `SHA256SUMS.txt`。APK SHA256：`39e96a6ac06ef7d43aae96af530edebc71478f48605e1eec10ea0f4786f5d9f5`。首次部署前阅读 README 与 INSTALL，验收范围见 ACCEPTANCE 与 VALIDATION。

## 转为正式发布前

本轮已在原表独立环境完成：`00-Setup.cmd` 首次部署、表端安装 / 停用 / 启用 / 卸载 / 重装、fixed / auto / original / 圆角与恢复，以及整机重启后的独立恢复（电脑保留 ADB 取证与输入连接，未声称物理断开）。转正式发布前仍建议在一块没有其他注入环境的空白已 root 适配手表上复跑；如果修改 APK，提升 versionCode 并更新所有校验清单。
