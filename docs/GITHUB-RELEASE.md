# OWOrnate 1.0.1-rc30 / code39 · 碰一下自动恢复

管理器 code39 和支付宝全局碰一下 0.2.1 新增开启状态记忆：启用后开机及 NFC 服务重启自动恢复，手动关闭后保持关闭。升级旧插件需先停用，再导入新版并开启一次。

原表已验证管理器同签安装、插件升级启用、NFC 进程重启和整表重启自动恢复，以及手动关闭后保持关闭。33 项控制器检查和 16 组状态记忆测试通过。重启后贴纸支付及长期功耗尚未复测；0.1.0 曾由用户反馈外出实际付款成功。守护不持唤醒锁，休眠时恢复可能延迟。

已有用户先同签更新管理器，然后停用旧插件、导入 `alipay-global-0.2.1.owo` 并开启一次。需要 root、Frida 16.7.19 和自行安装的 OPPO 渠道支付宝 3152。插件保留原支付宝确认流程和钱包 SE/AID 路由。
