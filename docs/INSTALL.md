# 安装与小组件接入

**当前版本：1.0.1-rc6 / versionCode 15。** 已构建签名并实机验证（原表 A.92）。

## 适用范围

面向已知共享环境：共享 Launcher Hook v9 / v10 / v11，配套 helper v6。独立莫奈环境本身可用，但不支持向独立宿主接入小组件。其他设备、Hook 或 helper 版本不在支持范围内。

## 首次安装与授权（需电脑）

完整解压 Windows 包，连接已开启 root adbd 的适配手表，运行 `00-Setup.cmd`。该入口安装 APK 并建立管理器的本机 root ADB 授权。安装包不负责获取 root。

如果管理器已有这份授权，后续更新 APK 可直接同签覆盖安装：

```
adb install -r OWOrnate-v1.0.1-rc6.apk
```

同签覆盖升级保留应用数据。只执行 `adb install` 不会建立首次 root ADB 授权；尚未授权时仍需运行 `00-Setup.cmd`。授权完成后，负一屏 Hook 接入、重新接入与外观开关在管理器内完成；后续 APK 更新仍通过电脑安装。

## 在管理器里接入 / 更新（手表内，无需电脑）

打开管理器 → **发现优化 → 负一屏小组件 → 接入负一屏**，在接入方案页确认后执行。流程复用管理器已有的本机 root ADB 授权，核对共享 Hook 与 helper 版本、备份现有 Hook、把 Hook 升级到 v11，然后重载一次表盘（约 10 秒黑屏）。接入后首页出现“负一屏小组件”。

从旧版本（Hook v9 / v10）升级也走同一个按钮：装好新 APK 后进这里点“接入负一屏”，它会把 Hook 升到 v11；已在 v11 上时此处显示“重新接入”，用于负一屏找不到卡片时的恢复。

## 隐藏小布助手（手表内）

接入后，进 **负一屏小组件** 页，页底“负一屏外观”里有「隐藏小布助手」开关。打开后负一屏不再显示小布那一行，下面的卡片顶上来；需要时随时关掉。切换下次打开负一屏即生效，不重载表盘。开关读取状态不需要 root，写入经管理器已有的 root 通道完成。

## 小组件

OWOrnate 信息、倒计时、课表三类卡片，尺寸 181×100dp。倒计时可显示系统“纪念日”里的日子。课表兼容拾光单表 JSON；不支持 ICS、完整备份或通用皮肤导入。在负一屏原生编辑页添加 / 移除卡片，点卡片本身再次设置；每类卡片只有一份设置，同类共用。

## 电脑备用入口（可选，仅用于恢复）

Windows 包的 `release-manage.ps1 -Action EnableWidgets`（`02-EnableWidgets.cmd`）用于更新共享 Hook 并重载 Launcher，作为管理器通道异常时的备用入口。日常通过管理器接入；首次授权仍用 `00-Setup.cmd`。电脑备用入口不替代管理器执行的系统进程白名单检查。
