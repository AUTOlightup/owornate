## 当时的发布前清单（历史）

在合适的空白、已有 root 的 OW20W1 / A.92 手表上完成：

1. 使用完整 Windows 包运行 `00-Setup.cmd`，核对授权与基础环境。
2. 断开电脑，在表端安装莫奈，确认实时配色、圆角及恢复设置。
3. 停用→启用→卸载→重装，核对每一步实际状态。
4. 整机重启，在首次打开 OWOrnate 前执行 `VerifyBoot`，确认独立恢复。
5. 记录设备类型、候选 APK SHA 和结果，再将发布状态改为正式版。

测试入口见 [INSTALL.md](INSTALL.md)。本轮为验收临时隔离了原表并随后恢复到原 code6 环境；该一次性例外已结束，后续默认仍不在生产表隔离模拟空白。
