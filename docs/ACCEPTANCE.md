## 正式发布前的最短实测清单

在用户的表上按顺序完成：

1. 逐项实测管理器动线：首页直接列出功能、发现优化按需出现、莫奈“更多选项”、各页图标、读状态时不闪不跳。
2. 倒计时离开自动保存：改一项后右滑，再进入应保留；只打开不改不应写入。
3. 纪念日模式：切到纪念日后的卡片与列表；授予“使用情况访问”是否生效（切回后应无记录）；在纪念日里加或删一条后息屏再亮屏，卡片是否更新；点卡片打开纪念日，改完回负一屏 30 秒内是否更新。
4. 三类卡片在负一屏的显示与添加、移除；课表卡片上课时右上角“还有 N 分钟”的显示。
5. 整机重启一次，核对重启后的恢复（引导脚本 supervisor、Hook 加载、卡片更新）。

记录设备类型、候选 APK SHA 与结果；发布状态仅在实际创建 Release 后更新。安装入口见 [INSTALL.md](INSTALL.md)。

## 当时的发布前清单（历史）

在合适的空白、已有 root 的 OW20W1 / A.92 手表上完成：

1. 使用完整 Windows 包运行 `00-Setup.cmd`，核对授权与基础环境。
2. 断开电脑，在表端安装莫奈，确认实时配色、圆角及恢复设置。
3. 停用→启用→卸载→重装，核对每一步实际状态。
4. 整机重启，在首次打开 OWOrnate 前执行 `VerifyBoot`，确认独立恢复。
5. 记录设备类型、候选 APK SHA 和结果，再将发布状态改为正式版。

测试入口见 [INSTALL.md](INSTALL.md)。本轮为验收临时隔离了原表并随后恢复到原 code6 环境；该一次性例外已结束，后续默认仍不在生产表隔离模拟空白。
