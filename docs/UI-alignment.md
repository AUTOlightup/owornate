# 界面与设计原稿对齐

本文件记录 OWOrnate 当前源码的原生界面与设计原稿的对应关系。设计原稿指 `腕上工坊-界面设计` 中的 UI 设计与开发规范 v1.0、`界面清单.json` 与交互原型；页面结构与尺寸以原设计稿为基准；下表按当前 `MainActivity.java` 与 `WorkshopUi.java` 整理。本轮按用户要求调整流程：首页只保留“我的优化”“发现优化”两个栏目、去掉子标题与“最近操作”“返回表盘”；已安装项进入统一的莫奈配置页并实时提交；“发现优化”始终进入商店式介绍页。本文件只记录对应关系，不生成模拟截图，也不代替实机验收结论；历史验证证据以 [验证记录](VALIDATION.md) 为准。

## 设备与画布

- 画布 201×238dp / 402×476px / density 2 / API 27 / armeabi-v7a。
- 页面左右边距 8dp，内容单列纵向滚动，尾部保留滚动余量。
- 正文 13sp，辅助 11sp，一级标题 20sp，二级标题 17sp；主按钮与图标命中区不小于 44dp。
- 页头图标以 20dp 绘制、44dp 命中：`WorkshopUi.hitIcon` 用内边距把命中区补到 44dp，图标本身不放大。
- 系统 sans-serif，`sp` 跟随真实 fontScale，不使用缩小字号来塞入更多信息。

## 部署与目录口径

- 电脑一次部署：首次在电脑运行 Windows 包里的 `00-Setup.cmd`（等价于 `release-manage.ps1 -Action Setup`），安装管理器 APP、授权本机 ADB 公钥并部署基础运行文件与 APP 恢复服务；它不安装莫奈模块。
- 首发只内置莫奈一个模块。发现优化直接列出这一项的介绍入口并标注“外观 · 内置 · 无需联网”，不再单独渲染“外观”分类；其他模块与在线目录不在界面展示，不渲染行，也不做灰色占位。本轮不新增网络后端，也没有在线目录，安装与设备状态读取都不依赖联网。
- 表端安装取自 APK 内置资源，离线完成：安装方案显示“管理器内置 · 无需下载”，不下载、不重新安装基础环境。
- 首页 `summary` 的计数只统计真实纳入管理且状态已确认的模块，未读取成功时不显示“已确认”，未知数量显示“—”并使用中性色。

## 交互约定

- 一级页面提供设置入口；二级页面顶部左侧有 44dp 返回命中区，与标题一起滚动。
- 返回采用自定义右滑逐级返回：系统 `windowSwipeToDismiss` 设为 `false` 关闭系统“右滑关闭”，由 `MainActivity.dispatchTouchEvent` 识别右滑（水平位移大于 64dp 且明显偏水平）触发返回；只有首页等根页面右滑才退出应用。首页不再有“返回表盘”按钮。
- 从欢迎页出发时，导航栈记录的是首页而不是欢迎页（`welcome` 不入栈），离开欢迎页后返回落在首页；任何二级页面在栈为空时兜底回到首页（`returnHome`），只有首页或欢迎页在根位置返回才退出应用。
- `go` 复用导航栈中已经存在的目标页：目标已在栈内时回退到该页，避免“首次设置”“运行环境”等重复入栈形成返回循环。删除记录页、应用确认页与优化管理页后，同步整理返回栈、进程重建与操作结果路由：旧 `versions` → 配置页、旧 `records` → 首页、旧确认页 → 配置页并读取实际状态；升级或恢复页面不自动提交旧草稿，也不落入已删除的管理页。
- 配置页从哪里进入就返回哪里：从“我的优化”进入则回列表，从介绍页“打开配置”进入则回介绍。
- 实时提交与启停：选择配色方式、固定颜色或连续圆角后直接提交，页面内给出轻量反馈；连续快速修改只保留最新一次待提交配置，避免每次点击堆积请求，也不静默丢掉最后一次选择。提交进行中与启停、卸载等写操作串行，暂不可发起冲突操作，普通只读浏览仍可继续。
- 提交失败或超时：明确提示未确认，停止后续自动提交并回读实际状态，以回读结果恢复控件；读不到时标记待确认，并提供手动重试。已停用时配置仍可查看并默认禁用编辑，启用成功后再实时调整。
- 页头启用 / 停用开关：一次点击执行一次启停，处理时防重复触发，状态以操作后的读取结果为准；独立且不小于 44dp 的触控区域，与返回手势互不抢操作，提供“启用莫奈 / 停用莫奈”的可访问名称；状态未读明或处理中不把未知状态画成确定的关闭状态。
- 单选整行选择并给出辅助说明；开关点击整个 48dp 行，checked、文案与可访问描述同源。
- 固定色入口只在固定模式下展示：自动取色与系统原色页不渲染“固定颜色”行，避免出现无效的颜色入口。
- 只有收到宿主回执、并重新读取确认后，界面才显示已生效；预览与草稿只是展示数据。
- 共享组件只能停用或启用，配置页底如实说明不能单独卸载的原因，不显示为可卸载；共享模式下“系统原色 + 关闭圆角”也是合法的已启用配置，不能据此误判为用户停用。
- 状态同时用文字或图形表达，不只靠红绿区分；警示与错误语义不随主题改变。
