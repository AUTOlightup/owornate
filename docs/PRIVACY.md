# 隐私说明

本文件说明 OWOrnate 当前候选发布件在设备上申请什么、处理什么、不做什么。内容面向公开读者，不含个人路径、设备号、网络地址或私有日志。

## 收集与上传

- 本版不设账号、不做遥测、不上传使用数据。
- 本版没有在线安装与 OTA，当前不主动把任何数据发送到外部服务。
- 主题取色采样在设备上的既有宿主进程内完成，不把表盘背景或图片上传。

`INTERNET` 权限当前用于经本机回环地址 127.0.0.1 连接设备自身的 root adbd（本机 ADB 通道），不发起任何外部网络请求。

## 权限与组件

| 权限 / 组件 | 用途 | 边界 |
| --- | --- | --- |
| `INTERNET` | 连接本机回环地址 127.0.0.1 上的 root adbd（本机 ADB 通道） | 不发起外部请求、不上传数据 |
| `RECEIVE_BOOT_COMPLETED` | 开机后检查本包独立模块是否需要恢复 | 只恢复已安装且未停用的模块 |
| 无障碍服务（首次部署在独立设备上启用，不需手动开启） | 服务连接时与 Launcher 事件时各触发一次 ensure | 不读取或上传屏幕内容，不执行任意 shell，不监听端口 |
| 本机 root adbd | 设备自身的既有授权通道 | 只用于本包固定命令，不提供任意命令入口 |

app 侧没有 JobService、没有业务轮询、没有周期定时器，也不新开端口；开机广播与无障碍服务只做本包目录的一次性检查。无障碍是系统绑定服务，系统可能因此维持 app 进程；这里只说明它没有业务轮询、没有定时器、也不读取屏幕内容。

## 莫奈模块与设备上的数据

- 莫奈模块随签名 APK 内置，APK 自带 `theme.jar`、`hook.js`、`monet-service.sh`、`module-manage.sh`，安装时从 APK 资源复制，不联网下载。
- 模块文件先复制到本应用私有目录，再在用户在“安装方案”点“安装并启用”时放入运行目录 `/data/local/tmp/watchworkshop-runtime`。
- 主题草稿以及共享模式停用前的设置保存在本应用私有偏好。
- 应用前保存的恢复快照保存在既有宿主的私有目录，用于恢复最近一次设置。
- 读取到的主题状态只保留白名单字段，不落盘表盘路径、指纹或样式等个人表盘信息。
- 首次部署会在设备上保存 `install-state.json`，记录部署前的 adbd 端口、无障碍与白名单状态，供移除管理器时恢复。

## 不做什么

- 不读取、不上传聊天内容、个人词库或 QQ 数据。
- 私钥分开保存：设备侧 ADB 私钥在本应用私有目录内生成；APK 签名私钥与口令只保存在电脑上工程之外的私有目录。两者都不进入源码或发布内容。
- 日志不包含私钥或个人聊天内容。
- 在系统里卸载本应用会清除本应用自己的数据（含主题草稿）；它不会清除 QQ 数据、登录状态、输入法词库或系统 root。
- 手表端莫奈配置页底的卸载只移除本管理器安装的莫奈模块文件，保留管理器、基础运行文件、自有 ADB 公钥、系统 root、共享主题偏好与最初的基础状态。
- `RemoveManager` 移除本管理器部署的基础运行件，同样不清理 QQ 数据、登录状态、输入法词库或系统 root。
