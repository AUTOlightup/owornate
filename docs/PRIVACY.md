# 隐私说明

OWOrnate 无账号系统、遥测或在线课表同步。网络权限用于连接手表本机 root ADB，以及用户主动检查/下载更新时访问 GitHub 或插件声明的 HTTPS 更新源；远端服务会收到通常的网络连接信息。管理器不把课表、倒计时或主题配置上传到远端，没有后台定时更新或静默安装。

用户可导入并信任外部 root 插件。插件的 `status`、启停及配置动作均可执行作者代码；管理器不提供代码沙箱，不能保证第三方脚本不访问网络或其他数据。下文的固定操作说明只适用于管理器自身及其官方 launcher-v1 载荷，不代表任意第三方插件行为。

课表由用户通过系统文件选择器或粘贴文本导入，解析后保存于应用私有目录；倒计时和小组件选项也保存在本机。移除一张卡片会保留最近配置供重新添加使用，不等于删除全部配置。卸载应用会清除应用私有数据；用户选择的原始导入文件不受影响。

管理器自身执行固定的协调操作。莫奈、负一屏小组件、截屏与录屏的 launcher-v1 功能载荷来自用户导入并确认信任的 `.owo`；管理器 APK 提供统一管理、原生设置和采集服务。管理器核对已知共享 Hook v9/v10/v11/v12/v13 和 helper v6，在用户确认接入或重新接入时备份并写入目标 Hook、定向重载 Launcher，并检查本应用的系统进程白名单。Windows Setup 不修改共享 Hook，也不复制、导入或部署 `.owo`；旧 `02-EnableWidgets.cmd` 只打开管理器。隐藏小布助手开关经同一通道写入固定的系统设置项。管理器使用首次设置授予的本机 root ADB 权限，不提供任意命令输入。Hook 及备份位于共享运行目录，卸载管理器不会移除其他共享功能或 QQ 数据。

新用户自有运行组件位于 `/data/local/tmp/watchworkshop-runtime`，按模块固定动作安装、启停和移除；组件本身不接管 QQ、NFC 或应用隐藏。功能移除保留管理器基础授权、用户设置和媒体，基础环境仅在显式 RemoveManager 且没有已安装功能时清理。

倒计时的“纪念日”模式会读取系统快应用“纪念日”保存在本机的数据（标题和日期），用同一条本机 root 通道、固定命令只读取这一份文件，从不修改它；读到的内容只保存在本应用私有目录，用来显示卡片，不上传。切到该模式时，管理器经 root 给本应用授予“使用情况访问”，只用来判断快应用引擎有没有到过前台（据此决定亮屏时要不要重读）；切回“自己设置”时撤回。

插件更新只在用户主动检查时下载，校验清单 ID、版本、大小和 SHA-256 后仍需用户确认信任或交给系统安装器；没有后台轮询。APK 更新还要求原包名、更高版本与原签名。第三方更新源及其作者都需要用户信任，摘要不等于作者签名。

发布包不包含签名私钥、口令、ADB 私钥、用户课表、设备备份或个人设备识别信息。许可证见 [THIRD-PARTY.md](THIRD-PARTY.md)。各构建的设备确认范围与待测项目见 [VALIDATION.md](VALIDATION.md)；code29 已完成共享环境覆盖安装、插件 1.1.0 升级和声明式设置往返验证，完整 Windows Setup、系统安装器在线覆盖、自有 v3、重启和实际录制仍待实机验收。

截屏与录屏使用本机 root 通道调用管理器内置的固定包装脚本和系统 screencap/screenrecord。截图保存到 `Pictures/Screenshots`，视频保存到 `Movies/Screenrecords` 并交给本机媒体扫描，不上传。录屏无声，前台服务在录制期间持有有限亮屏锁，结束后释放。停用模块保留已有图片、视频及画质设置；公开入口仅接受固定动作，不接收任意命令或输出路径。
