# 隐私说明

OWOrnate 无账号系统、遥测或在线课表同步。现有实现的网络权限用于连接手表本机 root ADB；不把课表、倒计时或主题配置上传到远端。

课表由用户通过系统文件选择器或粘贴文本导入，解析后保存于应用私有目录；倒计时和小组件选项也保存在本机。移除一张卡片会保留最近配置供重新添加使用，不等于删除全部配置。卸载应用会清除应用私有数据；用户选择的原始导入文件不受影响。

管理器内接入只执行 APK 内置的固定操作：核对共享 Hook v9/v10/v11 和 helper v6、备份旧 Hook、写入 v11、重载 Launcher，并检查本应用的系统进程白名单。隐藏小布助手开关经同一通道写入固定的系统设置项。它使用首次部署授予的本机 root ADB 权限，不提供任意命令输入。Hook 及备份位于共享运行目录，卸载管理器不会移除其他共享功能。

倒计时的“纪念日”模式会读取系统快应用“纪念日”保存在本机的数据（标题和日期），用同一条本机 root 通道、固定命令只读取这一份文件，从不修改它；读到的内容只保存在本应用私有目录，用来显示卡片，不上传。切到该模式时，管理器经 root 给本应用授予“使用情况访问”，只用来判断快应用引擎有没有到过前台（据此决定亮屏时要不要重读）；切回“自己设置”时撤回。

发布包不包含签名私钥、口令、ADB 私钥、用户课表或设备备份。许可证见 [THIRD-PARTY.md](THIRD-PARTY.md)。本版已有部分实机确认，完整范围与待测项目见 [VALIDATION.md](VALIDATION.md)。
