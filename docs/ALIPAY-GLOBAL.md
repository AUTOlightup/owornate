# 支付宝全局碰一下

插件 `dev.owornate.alipay-global`，0.1.0 / code1，包名 `alipay-global-0.1.0.owo`。

## 准备与开启

1. 适配 OW20W1 / A.92 / Android 8.1 API27 / armv7，已具备 root 和 Frida 16.7.19 注入环境。首次使用先按 [安装说明](INSTALL.md) 设置 OWOrnate；现有共享 WatchHide 环境可沿用其 Frida 工具。
2. 自行安装并登录 OPPO 渠道支付宝 10.6.41.260917 / code3152。该 APK 不随本项目分发。
3. 把 `.owo` 放到手表 `Download`，从“发现优化 → 本地插件”导入并确认信任。
4. 进入“支付宝全局碰一下”，打开右上开关；“息屏识别”默认“允许息屏”，也可选“仅亮屏”。
5. 从任意普通界面或息屏靠近适配的支付标签。读到后短震动 80ms、唤醒并打开原支付宝，由原应用显示商户、输入金额和确认付款。

开机或 NFC 进程重启后不会自动恢复，需回插件设置重新开启。当前 NFC 进程内可停用、再开启，保留配置；停用采用惰性 Hook，进程退出时才完全移除。无需“碰一下试验”测试应用。

## 已验证的范围

已验证插件导入、启停、配置、卸载重导入，亮屏与真正息屏下识别贴纸、自动打开支付宝和短震动。钱包中一张模拟卡的信息读取与标签发现可共存，不需停用钱包。

2026-10-27 22:23（UTC+8），用户外出碰一碰付款成功并提供成功照片；此项为用户现场反馈。照片与付款详情不随发布包上传。

收款账号与手表登录账号相同的贴纸，此前实测会显示“暂不支持该场景”；这类业务拒绝不能据此判断 NFC 未读到。请使用有权测试且收付款账号不同的场景，保留原支付宝支付确认流程。

带屏蓝环、锁屏、轻智能、长期耗电和实际门禁／闸机仍未验收。前台其他应用占用 NFC reader 时，保留其优先权。

## 实现与排查

插件在真实 `com.android.nfc` 进程监听普通 NfcA 标签，匹配原 SDK 支持的标签内容后进入原支付宝 NFC 入口，不使用全天 reader mode，不更改 SE/AID 路由。只包含清单与脚本，不修改支付宝 APK、机型、签名、账号或支付结果。

读不到时先确认 NFC 已开启、插件状态为启用、环境与支付宝版本匹配；若只是重启后停用，重新开启即可。出现错误先刷新查看实际状态，不对同一个 NFC 进程重复手动注入。

源码位于完整源码包 `plugins/alipay-global/`，构建与控制器测试见该目录 README。
