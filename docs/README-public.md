# OWOrnate 公开说明

**当前预发布：1.0.1-rc6 / versionCode 15。** [下载 v1.0.1-rc6](https://github.com/AUTOlightup/owornate/releases/tag/v1.0.1-rc6)。code15 已构建签名并同签安装；安装交接记录确认共享 Hook v11 已接入。功能验收范围见下文，历史 code7 至 code14 的结果不直接作为本版验收。

OWOrnate（`dev.codex.watchworkshop`）是面向 OPPO Watch 2 的原生 Android 管理器。本版在控制中心莫奈取色之外，提供三类负一屏小组件与负一屏外观开关。

## 本版内容

- 三类负一屏小组件：OWOrnate 信息、倒计时、课表，卡片 181×100dp。每类只有一份设置，同类卡片共用；在负一屏原生编辑页添加或移除卡片，点卡片再次设置。
- 倒计时可选“自己设置”或系统“纪念日”（只读接入快应用里的日子），离开设置页自动保存；只打开看一眼不会写入。
- 负一屏外观：接入后可把负一屏顶部小布助手那一行隐藏，需要时再打开；切换下次打开负一屏生效，不重载表盘。
- 管理器：首页直接列出已安装的功能，“发现优化”只在还有可安装项时出现；接入、重新接入与隐藏小布助手开关都在管理器里。
- 莫奈取色：配色方式、固定颜色与连续圆角实时生效；刷新配色、恢复上一次设置与卸载收在“更多选项”里。

## 共享环境接入

在已完成首次管理器授权的共享环境中，从管理器内“发现优化 → 负一屏小组件 → 接入负一屏”完成接入：复用现有 root ADB 授权，核对共享 Hook v9/v10/v11 与 helper v6，备份现有 Hook，升级到 v11 并定向重载一次表盘。已在 v11 上时这里是“重新接入”，用于负一屏找不到卡片时恢复。

首次安装与 root ADB 授权用电脑运行 `00-Setup.cmd`。授权完成后，接入、开关与日常使用在手表上完成；后续 APK 升级仍在电脑上同签覆盖安装。电脑包里的 `02-EnableWidgets.cmd` 可备用更新共享 Hook；系统进程白名单仍由管理器检查。

此接入只面向已知共享环境。独立莫奈环境仍可使用，但目前不支持把小组件接入独立宿主环境。

## 小组件与范围

- 课表支持拾光单表 JSON 导入；不支持 ICS、完整备份或通用皮肤导入。
- 纪念日模式只读取系统快应用“纪念日”里的数据，不修改它。
- 仅适配已知共享 Hook v9/v10/v11 + helper v6 环境；其他宿主、设备或版本不作兼容承诺。
- 没有在线目录，也没有应用内自动更新：升级方式是在电脑上同签覆盖安装新 APK，再在管理器里重新接入。
- 管理器首次设置与共享环境的条件见 [安装说明](INSTALL.md)。

## 验收状态

隐藏小布助手开关（含管理器里的开关来回切换）已由用户在表上实测确认；安装版本、接入状态、当前加载的 Hook 版本与安装后无崩溃已按设备回读核对。其余管理器改动（首页直接列出功能、倒计时离开自动保存、更多选项、图标外观、读状态不闪不跳）已随本版装表，用户尚未逐项反馈；纪念日模式随本版装表，尚未实测。小组件与接入方面的历史证据来自 code8 / code9，不是本版验收。详见 [VALIDATION.md](VALIDATION.md) 与 [ACCEPTANCE.md](ACCEPTANCE.md)。
