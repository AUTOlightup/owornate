# OWOrnate

**当前预发布：1.0.1-rc8 / versionCode 17。** [下载 v1.0.1-rc8](https://github.com/AUTOlightup/owornate/releases/tag/v1.0.1-rc8)。已在 OPPO Watch 2 / A.92 上同签覆盖安装并完成本轮实机验证，具体范围见 [验证记录](VALIDATION.md)。

OWOrnate（`dev.codex.watchworkshop`）是面向 OPPO Watch 2 的原生 Android 管理器，提供莫奈取色、负一屏小组件、截屏与录屏三个模块。

## 本版变化

- 新增“截屏与录屏”模块，可在发现页安装、首页管理和启停。控制中心第二页短按截屏，面板收起后保存 PNG；短按录屏先选画质，返回原界面后开始，再按同一按钮停止。长按两个按钮分别打开 OWOrnate 截屏页和录屏设置页。
- 使用系统原生录制：原分辨率 H.264/MP4、无声、单段最多 180 秒，码率 0.6 / 1.2 / 2.4 Mbps，默认 1.2 Mbps。输出帧率随画面更新变化，不提供固定帧率选项，也不保证 60fps。详见 [原生捕获说明](截屏录屏-原生版.md)。
- 修复共享 Hook 识别与错误展示。读取失败保留上次确认状态，单独显示错误及重试入口，避免误报为未安装或首次部署。
- 管理器与信息卡片共用运行状态；确认值、确认时间和读取错误分开保存。打开管理器或刷新状态不再自动恢复组件或修改后台白名单，恢复与修复通过明确入口执行。

## 已有功能

- 三类负一屏小组件：OWOrnate 信息、倒计时、课表，卡片 181×100dp。每类共用一份设置，在负一屏原生编辑页添加或移除，点卡片再次设置。
- 倒计时支持自己设置或只读接入系统“纪念日”，离开设置页自动保存；课表支持拾光单表 JSON，不支持 ICS、完整备份或通用皮肤导入。
- 可隐藏负一屏顶部小布助手；莫奈的配色方式、固定色和连续圆角实时生效。

## 安装与接入

首次安装和本机 root ADB 授权需用 Windows 包运行 `00-Setup.cmd`；安装包不负责获取 root。已有授权的用户可用电脑同签覆盖安装新 APK，保留数据，再从管理器对应模块页接入或重新接入。安装步骤见 [INSTALL.md](INSTALL.md)。

共享接入识别已知 Hook v9/v10/v11/v12 与 helper v6，备份并更新到 v12，定向重载一次 Launcher。小组件与捕获模块仅适配已知共享宿主环境；独立莫奈仍可使用。没有在线模块目录或应用内自动更新。

## 验证范围

code17 已验证原表上的三个模块状态、捕获模块启停、控制中心按钮与两个长按入口、表盘 PNG、手动录屏停止和 180 秒到时保存；录制结束后前台服务及亮屏锁释放，视频解码通过。状态存储 17/17、信息卡快照 13/13、捕获模拟 14/14、控制中心行为 6/6、小组件管理模拟 97/97、生命周期模拟 85/85 通过。

第三方应用采集、三档画质与高运动帧率比较、长期功耗、锁屏/MCU/轻智能及整机重启恢复仍待验证。纪念日与旧小组件完整交互未由本轮重新验收，历史记录不能替代本版结论。详见 [ACCEPTANCE.md](ACCEPTANCE.md)。
